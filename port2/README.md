# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern Styling**: Clean, professional design with gradient accents
- **Smooth Animations**: Scroll animations and smooth transitions
- **Mobile Menu**: Responsive navigation with mobile toggle
- **Project Showcase**: Display your best work with project cards
- **Skills Section**: Organize your technical skills by category
- **Contact Form**: Simple contact form for visitor inquiries
- **SEO Friendly**: Semantic HTML structure for better search engine visibility

## Sections

1. **Navigation Bar**: Fixed header with smooth scroll links
2. **Hero Section**: Eye-catching introduction with call-to-action buttons
3. **About Section**: Personal introduction and key statistics
4. **Projects Section**: Showcase your featured projects
5. **Skills Section**: Display technical expertise
6. **Contact Section**: Contact form and social links
7. **Footer**: Copyright and additional links

## Customization

### Personal Information
Edit the following in `index.html`:
- Replace "John Doe" with your name
- Update the tagline and description
- Add your actual contact information
- Update social media links

### Colors
Modify the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... other colors ... */
}
```

### Projects
Replace placeholder projects in the Projects section with your actual work:
- Add project images
- Update project descriptions
- Change technology tags
- Add real project links

### Skills
Update the skills list in the Skills section to match your expertise.

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize the content with your own information
4. Deploy to your hosting provider
